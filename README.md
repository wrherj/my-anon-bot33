# Анонимный Telegram-чат

Готовый бот на Python и aiogram. Он собирает пол и возраст, подбирает пары
мужчина-девушка и анонимно копирует сообщения между двумя пользователями.

## Как работает

- Только пользователи 18+.
- В анкете указываются пол и возраст.
- Подбор идёт между мужчиной и девушкой. Собеседнику показывается только возраст.
- Бесплатный диалог длится заданное число минут. После этого оба пользователя
  автоматически возвращаются в поиск, но друг с другом сразу повторно не соединяются.
- Если хотя бы у одного человека в паре есть подписка, у диалога нет таймера.
- Кнопка `Следующий` меняет собеседника в любой момент.
- Кнопка `Остановить` выводит на главное меню, а оставшемуся человеку ищет новую пару.
- Жалоба завершает диалог и блокирует повторную встречу этой пары.
- Текст, фото, видео, голосовые, файлы и стикеры копируются без ссылки на аккаунт
  отправителя. Контакты и геолокация не пересылаются.
- Сообщения пользователей в базе не сохраняются.

Подписка оформляется на 30 дней через Telegram Stars и автоматически продлевается,
пока пользователь не отключит её в Telegram. Для цифровых услуг внутри Telegram
это официальный способ оплаты. Бот проверяет сумму и владельца счёта, сохраняет ID
платежа и обрабатывает повторные списания идемпотентно.

## Быстрый запуск через Docker

### 1. Создай бота

1. Открой [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot`.
3. Задай имя и username.
4. Скопируй выданный токен.

### 2. Настрой проект

В папке проекта скопируй `.env.example` в `.env`:

```bash
cp .env.example .env
```

В Windows PowerShell вместо этого используй `Copy-Item .env.example .env`.

Открой `.env` и замени минимум эти значения:

```env
BOT_TOKEN=токен_из_BotFather
SUPPORT_CONTACT=@твой_аккаунт_поддержки
```

По желанию поменяй:

```env
SUBSCRIPTION_PRICE_STARS=199
FREE_CHAT_MINUTES=15
ADMIN_IDS=123456789
```

Свой числовой Telegram ID можно узнать у [@userinfobot](https://t.me/userinfobot).

### 3. Запусти

```bash
docker compose up -d --build
```

Посмотреть логи:

```bash
docker compose logs -f bot
```

Остановить:

```bash
docker compose down
```

База данных хранится в Docker volume `bot_data` и не пропадает после перезапуска.

## Запуск без Docker

Нужен Python 3.12+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Для локального запуска поменяй путь к базе в `.env`:

```env
DATABASE_PATH=data/anonymous_chat.db
```

Затем запусти:

```bash
python -m bot
```

На Windows активация окружения выглядит так:

```powershell
.venv\Scripts\activate
```

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Запуск и главное меню |
| `/search` | Начать поиск |
| `/next` | Сменить собеседника |
| `/stop` | Остановить диалог |
| `/profile` | Посмотреть или изменить анкету |
| `/subscription` | Статус и покупка подписки |
| `/rules` | Правила общения |
| `/report` | Жалоба на текущего собеседника |
| `/paysupport` | Контакт по вопросам оплаты |
| `/stats` | Статистика, только для `ADMIN_IDS` |

## Проверка тестов

После установки зависимостей:

```bash
python -m unittest discover -v
```

Тесты проверяют подбор по полу, таймер бесплатной пары, подписку, блокировку после
жалобы и защиту от повторной обработки платежа.

## Важные ограничения

- SQLite и локальная блокировка рассчитаны на один процесс бота. Не запускай две
  копии контейнера одновременно с одной базой.
- Для большой аудитории лучше заменить SQLite на PostgreSQL, хранить состояние в
  Redis, добавить отдельную админку модерации и резервные копии.
- Перед публичным запуском заполни контакт поддержки, политику конфиденциальности
  и условия подписки под требования своей страны.
- Telegram требует обрабатывать запросы по оплате через `/paysupport`.
